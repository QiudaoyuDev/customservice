## 后端文档解析依赖缺失修复 (DocumentTextExtractor)
- `repos/backend/src/main/java/com/hardwareai/support/knowledge/DocumentTextExtractor.java` 使用了 PDFBox 3.0 API（`org.apache.pdfbox.Loader.loadPDF(byte[])`），但 `pom.xml` 原本没有引入 pdfbox / poi 依赖。
- 已在 `pom.xml` 添加 `org.apache.pdfbox:pdfbox:3.0.2` 与 `org.apache.poi:poi-ooxml:5.2.5`。
- 注意：PDFBox `Loader` 类仅在 3.0+ 存在，2.x（如 2.0.32）会编译报“找不到符号 Loader”。必须用 3.0.x。
- 现象：IntelliJ 报“程序包 org.apache.pdfbox 不存在”是因为 `backend.iml` 未同步 Maven 依赖，需在 IDE 内 Reimport Maven / Invalidate Caches 才能生效（jar 实际已在 ~/.m2 下载成功）。
- 系统 Maven 版本过低：`maven-compiler-plugin:3.13.0` 需要 Maven ≥ 3.6.3，命令行 `mvn compile` 会失败，与代码无关。建议用 IDE 内置 Maven 或升级 Maven。

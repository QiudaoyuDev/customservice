## 知识库(Documents)页面：加载卡死 + 增改删补齐
- 用户报 `/console/documents` 一直显示"加载中"，并问新增/修改/删除操作是否齐备。
- 根因1（致命）：DocumentsPage 初始 `useEffect` 无 try/catch，一旦 `listDocuments()`/`listProducts()` 抛错（后端 401/403/500 或 hang 超时），`setLoading(false)` 永不执行 → 永久"加载中"。已改为 try/catch/finally + 错误态 + 重试按钮。
- 根因2（数据形态错配）：页面原用小写状态值 `uploaded/parsing/ready/failed` 与 `d.language`，但后端 `KnowledgeDocument.status` 返回大写 `UPLOADED/SUBMITTED/APPROVED/PUBLISHED/DEPRECATED/ARCHIVED` 且有 `locale`。已修正 `docTone`、状态筛选选项、统计卡片计数、表格语言列与状态标签（标签复用已有的小写 `status.*` 键，运行时翻译）。
- 根因3（新增不可用）：`uploadDocument` 发送 `language` 字段，后端要求 `locale` → 上传 400。已改为发送 `locale`。
- 补齐"修改/管理"与"删除"：
  - "修改"在本架构=修订生命周期。后端 `KnowledgeController` 已有 `POST /api/knowledge-revisions/{id}/{submit,publish,approve,deprecate,archive,restore}`（需 ADMIN/KNOWLEDGE_REVIEWER）。前端在每行加"管理"按钮 → 弹窗按当前状态展示可用动作（UPLOADED→提交；SUBMITTED→批准/弃用；APPROVED→发布/弃用；PUBLISHED→弃用/归档；DEPRECATED/ARCHIVED→恢复），分别调 `api.ts` 新封装 `submitRevision/publishRevision/approveRevision/deprecateRevision/archiveRevision/restoreRevision`。
  - "删除"：后端此前无端点。已在 `KnowledgeController` 新增 `DELETE /api/documents/{id}`(ADMIN)，级联清理 revisions/chunks/ocrResults/applicability 与向量索引(`vectorIndex.removeRevision`，包 try/catch 防外部依赖缺失)；并在 `KnowledgeRepositories` 为 `KnowledgeRevisionApplicabilityRepository`/`KnowledgeOcrResultRepository` 增加 `deleteByRevisionId` 派生方法。前端加"删除"按钮 → 确认弹窗 → `deleteDocument`。
  - i18n 新增键（en/zh 双补）：documents.manage/deleteConfirm/deleteHint/noRevision/actionFailed、common.retry/saved。
- 验收：`npx tsc`/`npm run check:i18n`/`npm run build` 全部通过。
- 注意：`ButtonVariant` 仅 `default|primary|ai|danger|ghost`（无 `secondary`），UI 里"次级"按钮用 `default`。后端改动需重新编译/重启后端才生效。

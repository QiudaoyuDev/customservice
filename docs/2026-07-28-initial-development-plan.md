# 初版开发记录：领域与知识闭环

**版本：** v0.1.0  
**日期：** 2026-07-28  
**状态：** 实施中

## 目标

交付“管理员登录 → 产品/二维码配置 → 文档上传解析 → 审核发布 → 检索验证”的可运行闭环。基础设施复用 `infra/` 中的 PostgreSQL、MinIO、Qdrant、OCR、Embedding/Rerank。

## 已确认决策

- 后端：Java 21、Spring Boot、PostgreSQL、Flyway；按领域模块组织。
- 前端：React + TypeScript + Vite。
- 单实例单租户运行，但所有业务数据保留服务端强制的 `tenant_id` 边界。
- 管理端：本地账号、JWT、管理员/知识审核人/只读分析员角色。
- 知识源：PDF、DOCX、图片；图片只做 OCR 文字提取。
- 模型：OpenAI 兼容 Provider 配置与连通性接口；本轮不用于生成答案。
- 后台异步工作：数据库任务表 + 应用内 Worker；不引入消息队列。

## 本轮范围

1. 认证、RBAC、审计、产品型号与二维码绑定。
2. MinIO 原始文件存储、文档元数据、修订生命周期和索引任务。
3. PDF/DOCX/图片解析适配边界，发布/下架时同步索引状态。
4. React 管理台的登录、产品、二维码、文档与检索验证工作区。

不包含用户扫码对话、LLM 编排、诊断流程执行、真实人工渠道和运营看板；这些通过既定实体和 API 边界继续演进。

## 验收标准

- 管理员可创建产品和二维码；公开二维码解析只返回最小产品上下文。
- 上传的文档进入私有对象存储，并可完成草稿、审核、发布、下架状态转换。
- 未发布或适用范围不完整的知识不能被检索。
- 发布后的检索结果必须带来源标题、修订版本和适用范围。
- 后端 API 有认证与角色校验；跨租户访问、失效二维码和非法状态流转均被拒绝。

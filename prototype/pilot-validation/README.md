# 试点验证交互原型

入口：`index.html`

本原型用于验证首个试点的核心闭环，而不是覆盖全部后台页面：

1. 扫码识别 X100 / rev.B / FW 2.1.0 / EU；
2. 按已发布状态机进行 Wi-Fi 故障诊断；
3. 命中过热/烧焦气味后强制安全停止并生成交接包；
4. 人工接管、结案，并形成待审核的产品质量信号。

原型使用本地假数据和 `localStorage` 保存演示进度，不调用真实后端。可直接打开，也可在本目录启动静态服务器：

```bash
python3 -m http.server 8289
```

访问 `http://127.0.0.1:8289/`。
